# BugFix
A mod for "Diggles - The Myth of Fenris" (German: Wiggles) that fixes bugs of the original game: scripting errors,
wrong calculations, broken animations and missing or wrong texts. It does not change the gameplay on purpose,
it only makes the game behave like it was intended.

## What is fixed?
Some examples (the complete list with all versions is in the [changelog](CHANGELOG.md),
details are explained in the [wiki](https://github.com/DigglesMods/BugFix/wiki)):

- **Gnomes:** "forever pregnancy", babies older than 0 years at birth, wrong calculation of transport experience,
  relatives not recognized when searching a partner, food left in the inventory after spare time
- **Buildings:** stuck hospital, bowling alley and disco, error with 4 guests at the bar, sawmill with hamsters,
  grub farms, guard house syntax error, energy coverage of gym and hospital
- **Animations:** hospital, brothel (invisible gnomes) and some work-time idle animations
- **Mood:** wrong goal of spare-time activities, doubled mood loss due to bad sleep quality
- **Fenris:** not found in his lair in the lava world (and the console command `fix_fenris` to put him back
  if he was already removed before installing this mod)
- **Texts:** typos, missing techtree texts (gold, iron, crystal, bar service) and missing activity texts
- **Others:** wrong weapon/shield combinations, books not flying when dropped with F9, AI syntax error

## Installation
1. Install the [DigglesModManager](https://github.com/DigglesMods/DigglesModManager) (the release zip already contains this mod).
   Alternatively download the mod from the [releases](https://github.com/DigglesMods/BugFix/releases) and extract it into the `Mods` directory.
2. Start the DigglesModManager, activate "BugFix" and click "Let's Mod".
3. Start the game as usual.

The mod supports the German, English, French, Spanish, Italian, Dutch, Polish, Russian and Czech game versions.

## Compatibility
- Requires DigglesModManager 1.0.0 or later.
- Can be combined with other mods. The bugfixes of the [RevisedPlanner](https://github.com/DigglesMods/RevisedPlanner) mod
  were moved here, so both mods should be used together.
